# ERASE Statement

<!-- keywords: ERASE -->

Releases an array.

## Syntax

`ERASE` *array* [ , *array* ]...

## Comments

The array is set to `Nothing`: declare or `REDIM` it again before using it.

## Example

```vb
ERASE scores
```
