# CALL Statement

<!-- keywords: CALL -->

Transfers control to a procedure.

## Syntax

[ `CALL` ] *name* [ ( *arguments* ) ]

## Comments

`CALL` is optional. The arguments go in parentheses: QuickVB puts them there for you when you leave a line written the QuickBASIC way (`Greet "Ann"`).

## Example

```vb
CALL Greet("Ann")
Greet("Bob")
```
