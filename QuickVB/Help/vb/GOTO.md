# GOTO Statement

<!-- keywords: GOTO -->

Jumps to a line label.

## Syntax

`GOTO` *label*

*label*:

## Comments

A label is a name followed by a colon at the start of a line. Structured statements (`IF`, `FOR`, `DO`) are usually clearer.

## Example

```vb
GOTO done
PRINT("skipped")
done:
```
