# QuickVB Survival Guide

<!-- keywords: SURVIVAL -->

The few things you need to start writing and running programs.

## Write and run

- Type a program in the editor. The one you start with prints *Hello World!*.
- Press **F5** to run it. When it ends, press a key to return to the editor.
- Press **Shift+F5** to start it again from the beginning.
- Compiler errors show as you type; the status line tells you what is wrong with the line.

## Menus and keys

- Press **Alt** and the highlighted letter to open a menu (**Alt+F** is File), or click it with the mouse.
- **F1** shows help for the word under the cursor, **Shift+F1** explains how to use Help, and **Esc** closes it.
- **F6** moves between windows, **F4** shows the output screen of the program.
- **Alt+Backspace** takes back the last edit.

## Files

- **File > New Program** starts again with Hello World, **Open Program** loads a `.bas`, `.vb`, `.vbproj` or `.sln`, **Save** and **Save As** write it.
- **File > Samples** has the classic games Nibbles and Gorilla: open one and press F5.
- **File > Save As Project** writes a `.vbproj` that builds and runs anywhere with `dotnet run`.
- **File > Make EXE File** writes a program you can give to others.

## QuickBASIC statements

Statements like `PRINT`, `LOCATE`, `INPUT` and `SCREEN` work as they did in QuickBASIC: QuickVB imports what the program uses. Press **F1** on one to see how it is used.

## Debugging

- **F9** sets or clears a breakpoint on the line, and **F5** then stops there.
- **F8** steps a statement at a time, **F10** steps over a call, **F7** runs to the cursor.
- **Debug > Add Watch** shows the value of an expression; **Shift+F9** shows one at the cursor.
