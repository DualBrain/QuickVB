# STOP Statement

<!-- keywords: STOP -->

Suspends the program so it can be examined.

## Syntax

`STOP`

## Comments

Under the debugger (F8, F10) the program stops here, as at a breakpoint. Outside the debugger it ends the program.

## Example

```vb
STOP
```
